# Design

We'd like to go with model-driven development for the inventory service. So we start with a model. The inventory should be the model. What we want to support for inventory is the ability to change the quantity of the inventory.

## Domain Model
The main model for the inventory should have three attributes. There should be an ID to identify the inventory uniquely. There should also be a sku code to indicate what the sku is for, and quantity Is a quantity of sku of the inventory.
